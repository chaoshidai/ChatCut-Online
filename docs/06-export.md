# 导出与交付

导出在本机执行。最终可用格式和选项取决于当前版本、工程内容与导出入口，常见交付包括 MP4、独立音频、SRT 字幕、FCPXML 和完整工程数据。

## 导出前检查

1. 从头到尾预览时间线。
2. 检查意外空隙、重叠、黑帧和超出源素材范围的片段。
3. 检查字幕拼写、断句、位置和安全区。
4. 检查人声、音乐、音效的相对响度。
5. 检查画幅、分辨率、帧率和总时长。
6. 确认目标磁盘有足够空间，并选择稳定的本地目录。

## 视频导出

通用发布优先使用 MP4/H.264。第一次导出建议先输出较短或较低分辨率的测试文件，确认效果后再导出最终版。

| 场景 | 建议 |
| --- | --- |
| 横屏网站/视频平台 | 16:9，按源素材选择 1080p 或更高 |
| 竖屏短视频 | 9:16，检查字幕和主体安全区 |
| 快速审片 | 较低分辨率或较低码率，文件名标注 `review` |
| 最终归档 | 使用源素材可支持的高质量设置，并保留工程 |

不要盲目把低分辨率源素材放大到 4K；文件会更大，但不会凭空增加细节。

## 透明内容

需要透明背景的单个图形或动效片段时，当前产品路径支持导出 ProRes 4444 MOV。透明 WebM 转换在首版未开放；如果界面回退为 H.264，透明通道将无法保留。

## 音频、字幕和工程数据

- **独立音频**：适合播客、混音或交给其他软件处理。
- **SRT 字幕**：适合平台外挂字幕和人工校对。
- **FCPXML**：用于与支持该交换格式的软件继续协作，导入后仍应逐项核对效果。
- **完整工程数据**：用于备份和迁移；工程文件不一定包含所有源素材副本。

## 导出失败排查顺序

1. 确认保存目录可写且空间充足。
2. 改用短时间范围或 1080p 测试导出。
3. 检查最近添加的损坏素材、异常特效、字幕或生成片段。
4. 关闭其他占用大量显存、内存或磁盘的程序。
5. 重启客户端后再试；若仍失败，在设置中导出脱敏诊断包。

不要重复覆盖唯一的成片文件。建议使用 `项目名-画幅-日期-v01.mp4` 这类可追踪文件名。

## 交付验收

导出完成不代表交付完成。请用普通播放器从头到尾播放导出文件，并在最终发布设备上检查画面方向、色彩、音量、字幕和时长。
