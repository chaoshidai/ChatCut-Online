# 使用 AI Agent 剪辑

Agent 不是只给建议的聊天机器人。它可以读取当前工程，并把剪切、移动、添加素材等操作落到真实时间线上。结果仍然可以手动修改、撤销和继续编辑。

## 使用前提

- 已登录 ChatCut Online；
- 网络连接正常；
- 当前工程已经打开；
- 账号具有所需能力和足够积分；
- 重要工程已保存或备份。

平台统一提供 Agent 模型，不需要也不应在客户端寻找第三方 API Key 设置。

## 高成功率指令结构

一条好指令通常包含四部分：

```text
范围 + 动作 + 目标效果 + 不要改变的内容
```

示例：

```text
只处理 00:10 到 00:35。删掉无声停顿，让节奏紧凑；不要移动背景音乐，也不要修改 00:35 之后的内容。
```

## 推荐工作方式

### 1. 先读后改

面对复杂工程，先让 Agent 说明它识别到的轨道和片段，再要求修改：

```text
先查看当前时间线，告诉我主视频、背景音乐和字幕分别在哪些轨道，暂时不要修改。
```

### 2. 一次完成一个目标

把“粗剪、加字幕、配音乐、生成 B-roll、调色并导出”拆成多轮。每轮完成后预览并确认，出错时更容易定位和撤销。

### 3. 明确时间范围

使用 `00:15 到 00:42`、`第一个视频片段`、`第二条音频轨`等边界，少用“前面一点”“差不多这里”这类模糊描述。

### 4. 明确保护范围

告诉 Agent 哪些内容不能动：

```text
把第三个镜头缩短到 4 秒；不要移动后面的旁白，必要时只调整镜头出点。
```

## 常用指令示例

### 粗剪

```text
检查主视频轨，把明显的空白片头和片尾裁掉。先告诉我准备修改哪些时间段，再执行。
```

### 画面节奏

```text
只处理前 30 秒。找出时长超过 6 秒且没有明显动作变化的镜头，给我一份缩短建议，暂时不要修改。
```

### 音频

```text
把背景音乐放到独立音频轨，从 00:05 开始；音乐结束时做自然淡出，不要覆盖原视频人声。
```

### 添加生成素材

```text
在 00:12 附近需要一个 5 秒的城市夜景补充镜头。先给出生成提示词和预计积分，不要直接提交生成。
```

### 安全检查

```text
检查时间线是否存在意外空隙、重叠、黑帧风险或超出源素材长度的片段，只报告问题，不要修改。
```

## 收费与停止规则

Agent 对话和它调用的生成能力可能分别产生积分消耗。界面会显示连接、排队、生成和最终扣费状态。

- 尚未提交云端时取消，通常不会扣除该次任务积分。
- 请求进入生产队列后，即使停止等待，也不代表撤销云端请求或自动退款。
- 网络中断后客户端应恢复同一请求，而不是重复创建；不要连续重复点击。
- 最终扣费以服务端账单为准。

## Agent 理解错了怎么办

1. 立即停止继续追加指令。
2. 查看时间线和修改记录，确认影响范围。
3. 使用撤销恢复到修改前。
4. 把指令拆小，补充时间范围、轨道、对象和保护条件后重试。
5. 若发生重复扣费或任务状态不明，记录任务 ID 或 Trace ID，再联系客服；不要反复提交同一个生成任务。
