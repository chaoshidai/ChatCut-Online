# 故障排查

先记录客户端版本、操作系统、问题发生时间和可稳定复现的步骤。涉及收费任务时，先保存任务 ID 或 Trace ID，再排查；不要反复提交。

## 客户端无法启动

1. 确认安装包来自本仓库 Releases，且系统与架构受支持。
2. 重启电脑，再单独启动 ChatCut Online。
3. 暂时关闭占用大量 GPU、内存或端口的应用。
4. 如果客户端自动进入安全模式，先在安全模式中打开工程并导出诊断包。
5. 仍无法启动时，提交 Issue 并附启动时间、系统版本和脱敏诊断材料。

不要先删除工程目录或本地媒体目录。

## 一直显示离线

1. 确认其他 HTTPS 网站可以正常访问，排除整机断网。
2. 检查系统时间和时区是否准确。
3. 暂时关闭会拦截本地回环地址或 HTTPS 的代理、过滤器与安全软件后复测。
4. 换一个网络，排除公司网络、校园网或 DNS 策略影响。
5. 本地编辑和导出可继续进行；登录、购买、Agent 和生成需恢复联网。

## 无法登录

- **二维码过期**：重新获取，不要继续扫描旧二维码。
- **手机号格式错误**：输入 11 位中国大陆手机号。
- **图片验证码过期**：刷新图片后重新填写。
- **短信验证码未收到**：等待倒计时结束，检查拦截短信和手机号，再重试一次。
- **反复失败**：停止频繁请求，稍后再试或联系客服。

## Agent 没有响应或中断

1. 查看顶部 Agent 状态是否仍在连接、排队或生成。
2. 确认账号登录、余额和网络状态。
3. 如果请求已进入生产队列，不要重复发送相同指令。
4. 等待客户端恢复同一请求；中断等待不一定退款。
5. 恢复后先检查时间线是否已经发生修改。

## AI 生成失败

- **报价过期**：重新获取报价。
- **当前账号未开通模型**：更换当前可用模型或套餐。
- **模型维护中**：稍后重试，不要连续提交。
- **生成失败且已退款**：刷新积分余额。
- **状态未知/人工核对**：记录任务 ID 或 Trace ID，联系客服。
- **完成但无法下载**：检查磁盘空间、本地媒体目录写入权限和网络。

当前首版不支持参考图片、参考视频或参考音频生成；遇到对应提示不是 API Key 配置问题。

## 素材导入或预览异常

1. 确认源文件仍存在且可以被系统播放器打开。
2. 将文件复制到本地短路径目录，避免网络盘、临时目录和过长文件名。
3. 检查磁盘空间和目录权限。
4. 尝试用常见编码重新封装或转码副本，再导入副本。
5. 保留原始文件，不要直接覆盖唯一素材。

## 导出失败、卡住或结果异常

1. 改用可写的本地目录并确认空间充足。
2. 先导出 10 秒或 1080p 测试版本。
3. 临时禁用最近添加的特效、字幕或异常素材，定位问题片段。
4. 关闭其他高负载程序并重启客户端。
5. 如果正常模式持续失败，观察客户端是否提供安全模式或关闭硬件加速后的重试路径。
6. 导出脱敏诊断包后提交 Bug。

## 自动更新失败

前往 [Releases](https://github.com/chaoshidai/ChatCut-Online/releases/latest)确认是否确有新版本。灰度发布时，部分设备会显示“当前设备暂未开放”，这是正常状态。手动更新时先退出客户端，并只使用官方安装包。

## 提交高质量 Bug

使用 [Bug 模板](https://github.com/chaoshidai/ChatCut-Online/issues/new/choose)，至少包含：

- 客户端版本和安装包来源；
- Windows/macOS/Linux 版本与 CPU 架构；
- 可重复的最短步骤；
- 预期结果和实际结果；
- 是否涉及登录、扣费、生成或导出；
- 脱敏截图、任务 ID/Trace ID 或诊断包。

公开内容必须先脱敏。
