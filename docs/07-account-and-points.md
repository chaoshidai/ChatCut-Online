# 账号、套餐与积分

## 登录

点击客户端顶部的 **登录**，可选择：

- **扫码登录**：获取二维码后使用微信扫码；二维码只用于本次登录，过期后重新获取。
- **手机号登录**：输入中国大陆 11 位手机号，先完成图片验证码，再获取并填写短信验证码。

不要把登录二维码、短信验证码或图片验证码发给他人。离线时不能登录，但已有本地工程仍可编辑和导出。

## 账号菜单

登录后可查看：

- 当前套餐和有效状态；
- 当前可用积分；
- 套餐积分与通用积分；
- 付费、退款与续费规则入口；
- 帮助与客服；
- 退出登录。

离线缓存只用于展示有限的账号状态，余额、购买和权益应在联网后刷新确认。

## 积分扣减

当前规则是优先扣套餐积分，再扣通用积分。客户端可能只能显示余额汇总，不一定提供逐笔任务、时间、金额或退款明细。

Agent 对话和 AI 素材生成都可能消耗积分：

- 生成能力会先展示积分报价；
- 确认后才创建收费任务；
- 进入生产队列后停止等待，通常不会自动退还积分；
- 生成失败可能显示已退款、状态未知或人工核对；
- 最终结果以服务端余额、账单和正式协议为准。

## 购买套餐或积分包

1. 登录并保持联网。
2. 点击 **套餐**，按全部、月付、年付或积分包筛选。
3. 阅读客户端实时返回的价格和权益。
4. 勾选同意付费服务协议。
5. 选择套餐；升级或续订时按界面选择生效方式。
6. 使用安全收银台或支付二维码完成支付。
7. 回到客户端查询到账状态并刷新余额。

不要仅凭截图或本文判断当前价格、自动续费、生效日期或退款条件。以支付前的服务端报价、安全收银台、客户端购买界面和官网的[正式付费规则](https://chatcut.online/legal/billing)为准。

## 支付后未到账

1. 不要立即重复付款。
2. 在原支付窗口点击查询或确认到账。
3. 返回账号菜单刷新套餐与余额。
4. 等待支付渠道和服务端完成同步。
5. 仍未到账时记录脱敏订单号、支付时间、金额、客户端版本和 Trace ID，通过客户端账号菜单中的 **帮助与客服**或[官网客服入口](https://chatcut.online/support)联系支持。

公开 Issue 中不要上传完整订单凭据、付款码、手机号或未经打码的支付截图。

## 退出登录和本地数据

退出账号、套餐到期、购买或退款不会主动删除本地工程、源素材、已下载生成文件和导出文件。退出前仍建议完成重要工程备份。
