# 生成图片、视频、语音、音乐和音效

ChatCut Online 可以通过平台账号生成素材，并把结果下载到本地工程。当前支持文本生成图片、视频、语音、音乐和音效。

## 标准流程

1. 在 Agent 中说明素材类型、内容、用途和时长。
2. Agent 选择当前账号可用的模型和模式。
3. 客户端展示模型、关键参数、输出说明和积分报价。
4. 你确认后，客户端创建唯一的云端任务并扣费。
5. 任务完成后，产物下载到本地媒体目录并加入工程。
6. 在时间线上检查时长、画幅、声音和内容，再决定是否使用。

设置中可选择生成完成后是否自动下载，也可以设置默认图片、视频质量档位。可用档位和真实价格以客户端实时目录为准。

## 图片

推荐包含主体、环境、构图、光线、风格和画幅：

```text
生成一张 9:16 竖屏图片：夜晚的现代城市街口，路面有雨后反光，蓝紫色霓虹，主体区域留在画面中部，不要文字和水印。
```

生成后先检查人物肢体、文字、品牌标识和边缘细节。需要局部修改时，当前首版不支持上传参考图进行重绘，应重新整理纯文本提示词后生成。

## 视频

推荐写清主体、动作、镜头、环境、时长、画幅和声音要求：

```text
生成 5 秒 16:9 视频：清晨的海边公路，一辆白色汽车从远处驶近；低机位缓慢推镜，真实摄影风格，镜头稳定，不要字幕和水印。
```

短镜头通常比一条长提示词塞入多个场景更稳定。多个镜头请分开生成，再回到时间线剪辑。

当前首版不支持首帧、尾帧、参考图片、参考视频或参考音频驱动的视频生成。

## 语音

脚本要按口语写，明确语言、语气、语速和用途：

```text
把下面文字生成中文旁白：自然、可信、略带热情，语速稍慢，适合产品演示。正文：……
```

生成后检查专有名词、数字、单位和多音字。长旁白建议分段生成，方便只替换读错的一句。

## 音乐

说明用途、情绪、风格、速度、时长和是否纯音乐：

```text
生成 30 秒纯背景音乐：轻快科技感，约 110 BPM，前 3 秒快速建立节奏，中段保持克制，结尾自然收束，不要人声。
```

配到时间线后降低音量，确保不会遮盖人声。音乐循环或二次剪辑前先听拼接点。

## 音效

说明声音来源、质感、距离、空间和时长：

```text
生成一个 1 秒左右的界面确认音效：清脆、现代、轻微金属质感，不刺耳，短尾音。
```

一个提示词尽量只描述一个明确事件。

## 状态与异常

常见状态包括获取报价、等待确认、已排队、生成中、等待下载、已完成、失败退款、状态未知或人工核对。

- **报价过期**：重新获取，不要确认旧报价。
- **网络中断**：等待客户端恢复同一任务，不要重复提交。
- **生成失败且已退款**：刷新余额后再决定是否重试。
- **状态未知/人工核对**：保存任务 ID 或 Trace ID，联系支持。
- **完成但未下载**：检查本地媒体目录权限、磁盘空间和网络，再恢复下载。

生成内容仍需由用户检查其准确性、合规性和可使用权利。不要生成或发布侵犯他人隐私、版权、商标或人格权的内容。
