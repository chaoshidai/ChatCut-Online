# 已知限制

本文记录首个 ChatCut Online Electron 版本的公开能力边界。它不是永久路线图，后续版本以 Release Notes 为准。

## 暂未开放

| 能力 | 当前状态 | 建议 |
| --- | --- | --- |
| 云端自动转写 | 暂未开放 | 先使用手动字幕或外部字幕文件；等待正式更新 |
| 基于文字稿剪辑 | 依赖转写，暂不可用 | 使用时间线和 Agent 的时间范围指令 |
| 素材站搜索 | 暂未开放 | 导入自己有权使用的本地素材 |
| Agent 网页提取 | 暂未开放 | 手动整理必要文字后粘贴给 Agent |
| 远程代码沙箱 | 暂未开放 | 不影响常规时间线编辑 |
| 图片参考素材生成 | 暂未开放 | 使用纯文本描述重新生成 |
| 视频首帧/尾帧/参考素材生成 | 暂未开放 | 使用纯文本生成短镜头后手动剪辑 |
| 音频参考素材生成 | 暂未开放 | 使用文本生成语音、音乐或音效 |
| 透明 WebM | 暂未开放 | 透明交付使用 ProRes 4444 MOV |

## 需要联网和登录

Agent 对话、AI 生成、余额与套餐、支付确认和更新检查依赖平台服务。离线时只能继续使用已有的本地工程、素材和本地导出能力。

## 模型与套餐不是固定清单

可用模型由账号套餐、服务端目录、维护状态和运营策略共同决定。文档不承诺某个具体模型始终可用，也不写死价格或积分。

## 生成内容需要人工复核

AI 可能产生错误细节、不自然画面、错误读音或不适合发布的内容。使用者必须检查事实、版权、隐私、商标、肖像和平台规则。

## 平台安装包

只有 Releases 中实际提供的系统与架构才属于当前公开支持范围。不要因为仓库文档提到某种格式或技术栈，就推断某个平台一定已有安装包。
