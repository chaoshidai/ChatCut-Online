# 安装与首次启动

## 下载

只从 [ChatCut Online 官方网站](https://chatcut.online)、[ChatCut Online GitHub Releases](https://github.com/chaoshidai/ChatCut-Online/releases/latest)，或客户端内明确标出的官方更新入口下载。打开 Release 后：

1. 阅读版本说明中的支持系统、已知问题和升级提示。
2. 下载与你的操作系统及 CPU 架构匹配的文件。
3. 如果 Release 提供校验值，请在安装前核对。

如果最新 Release 没有适合你系统的安装包，表示该平台当前尚未公开支持。不要从第三方网盘或不明镜像下载。

## Windows 安装

1. 退出正在运行的旧版 ChatCut Online。
2. 双击从本仓库下载的安装程序。
3. 按安装向导完成安装，再从开始菜单启动。
4. 第一次打开后，新建空工程并进行一次短视频预览，确认显卡、音频和本地服务正常。

若系统拦截安装，请先确认发布者、文件来源和 Release 页面一致。不要为了安装未知文件而永久关闭系统安全防护。

## 首次启动检查

启动后建议依次确认：

- 首页可以创建工程；
- 顶部账号区能显示“登录”或当前账号；
- 本地视频可以导入并预览；
- **设置 → 本地存储**能显示媒体目录；
- 需要 Agent 或 AI 生成时，网络连接正常。

无需配置模型厂商、API 地址或第三方 API Key。ChatCut Online 商业客户端统一使用平台账号和云端 AI 服务。

## 登录是可选的吗

是。本地工程、已有素材的手动编辑和本地导出可以在未登录或离线时使用。以下能力需要登录并联网：

- Agent 对话与自动剪辑；
- 图片、视频、语音、音乐和音效生成；
- 套餐购买、余额刷新与支付状态确认。

登录方法见[账号、套餐与积分](07-account-and-points.md)。

## 更新

桌面客户端的 **设置 → 客户端更新**可检查更新。状态可能包括：已是最新版本、灰度发布暂未开放、发现更新、下载中、可安装或失败。

更新前建议完成当前导出并保留重要工程备份。只安装经过客户端校验或本仓库 Release 发布的更新。

## 卸载前

卸载应用不等于备份工程。请先：

1. 导出重要成片、字幕和工程数据。
2. 在设置中记下本地媒体目录。
3. 确认生成素材和源文件均已复制到安全位置。

不同版本或系统的卸载程序是否保留本地数据可能不同，不要把卸载当作清理账号或删除数据的方式。
