# 本地数据与隐私

## 什么保存在本机

ChatCut Online 桌面客户端的以下内容默认保存在本机：

- 工程数据；
- 导入的视频、音频、图片引用或副本；
- 从云端下载完成的 AI 生成素材；
- 本地导出的视频、音频、字幕和工程文件；
- 本地编辑所需的缓存和运行数据。

你可以在 **设置 → 本地存储**查看当前媒体目录。工程不使用商业客户端的云工程存储路径。

## 哪些操作需要联网

- 登录与账号状态刷新；
- Agent 对话；
- 图片、视频、语音、音乐和音效生成；
- 套餐目录、购买、支付确认和积分余额；
- 检查与下载客户端更新；
- 打开协议和客服网页。

联网服务会处理完成请求所必需的提示词、参数、账号授权和任务状态。具体数据处理规则以客户端登录界面和官网公布的[隐私政策](https://chatcut.online/legal/privacy)为准。

## 离线行为

网络断开时，已有本地工程仍可编辑和导出。登录、余额刷新、购买、Agent 与生成能力不可用。离线状态下看到的账号信息可能是缓存，不应视为最终余额或权益证明。

## 备份建议

重要项目至少保留三类内容：

1. 完整工程数据；
2. 所有源素材和已采用的生成素材；
3. 最终成片、字幕及其他交付文件。

最好将备份放在与工作盘不同的磁盘或可信存储中。仅复制工程文件可能无法带走外部源素材。

## 脱敏诊断包

遇到启动、导出或本地服务故障时，可在 **设置 → 运行诊断 → 导出脱敏诊断包**生成支持材料。

脱敏不等于可以不检查。提交前仍请解压或查看文件名和内容，确认没有手机号、真实姓名、访问令牌、支付凭据、私人提示词、完整本地路径或未公开素材。

## 安全反馈

安全漏洞不要提交到公开 Issue，也不要公开可利用细节。请按[安全问题报告指南](../SECURITY.md)联系维护者。
