# 完成第一个视频工程

本教程用一个 30～60 秒的视频说明从导入到导出的最短流程。

## 1. 新建工程

在首页选择新建工程，为它起一个能识别内容和版本的名字，例如 `产品介绍-竖屏-v1`。建议一个交付视频使用一个独立工程，方便备份和回退。

## 2. 导入素材

把视频、音频或图片拖入素材区，或使用导入按钮选择文件。导入后先逐个预览：

- 画面和声音是否完整；
- 横竖屏方向是否正确；
- 是否存在黑帧、损坏文件或明显音画不同步；
- 素材是否仍位于稳定的本地目录。

不要在编辑过程中移动、重命名或删除源文件，否则工程可能找不到素材。

## 3. 放到时间线

将主视频拖到视频轨起点。背景音乐放到独立音频轨，图片、字幕或动效放在更上方的轨道。让不同类型内容分轨，后续调整会更清楚。

## 4. 做一次基础剪辑

先手动完成三件事：

1. 删掉片头、片尾多余部分。
2. 分割并删除一次明显失误。
3. 拖动剩余片段，让它们首尾衔接且没有意外空隙。

播放剪切点前后几秒，检查是否突兀。如果删错，立即撤销，不要重新导入素材。

## 5. 可选：让 Agent 帮你剪

登录后打开 Agent 面板，输入一个边界明确的指令：

```text
只处理 00:05 到 00:20：删掉中间最长的停顿，其他片段不要移动。
```

Agent 的修改会落在真实时间线上。执行后检查修改记录和时间线，再决定继续、撤销或手动微调。更多写法见[使用 AI Agent 剪辑](04-ai-agent.md)。

## 6. 可选：添加 AI 素材

需要补充画面、配音、音乐或音效时，可以让 Agent 发起生成。客户端会先显示模型、参数和积分报价；确认后才创建任务。生成结果完成后可自动下载到本地工程。

第一次建议只生成一个短素材，熟悉完整流程后再批量制作。详见[AI 素材生成](05-ai-generation.md)。

## 7. 导出前检查

- 从头到尾完整预览一次；
- 检查剪切点、黑帧和时间线空隙；
- 检查人声、音乐和音效的相对音量；
- 检查字幕拼写、位置和安全区；
- 确认画幅、帧率、分辨率和文件名符合发布平台要求。

## 8. 导出

打开导出面板，先使用一个常规 MP4 预设进行测试导出。播放导出文件并确认时长、音画、字幕和清晰度无误，再输出最终高质量版本。

详见[导出与交付](06-export.md)。
