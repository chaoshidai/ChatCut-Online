# 常见问题

## ChatCut Online 是网页还是桌面客户端？

当前文档主要面向 Electron 桌面客户端。请从本仓库 Releases 下载当前公开支持的安装包。

## 需要自己购买模型 API Key 吗？

不需要。商业客户端统一使用 ChatCut Online 平台账号和云端 AI 服务，不向普通用户开放第三方供应商 Key、模型端点或服务地址配置。

## 不登录能用吗？

可以使用本地工程、手动编辑已有素材和本地导出。Agent、AI 生成、套餐购买和余额刷新需要登录并联网。

## 工程会自动上传云端吗？

商业桌面客户端的工程、导入素材、生成下载和导出保存在本机，不使用云工程存储。联网 AI 服务仍会处理完成请求所必需的数据，详见正式隐私政策。

## 支持哪些 AI 生成？

首版支持文本生成图片、视频、语音、音乐和音效。实际模型、参数、套餐限制和积分报价以客户端实时显示为准。

## 为什么不能上传参考图或首尾帧？

参考图片、参考视频、首尾帧和参考音频生成模式在首个 Electron 版本暂未开放。请使用纯文本生成，或等待后续版本。

## 支持自动转写和文字剪辑吗？

首版的 ChatCut Online 云端转写尚未开放，因此依赖转写的文字剪辑流程暂不可用。时间线编辑和按时间范围给 Agent 下指令不受影响。

## Agent 修改后还能手动改吗？

可以。Agent 的编辑会落在真实时间线上，仍可手动调整、撤销和继续编辑。

## AI 任务取消后会退积分吗？

尚未提交云端时取消通常不会创建收费任务；请求进入生产队列后，停止等待不代表取消生产或自动退款。以服务端最终账单和正式付费规则为准。

## 生成失败怎么办？

先看状态。如果显示已退款，刷新余额；如果显示状态未知或人工核对，记录任务 ID/Trace ID 并联系客服，不要重复提交。

## 离线时可以导出吗？

已有本地工程和素材通常可以继续本地导出。需要云端生成或账号校验的步骤无法在离线时完成。

## 可以导出什么？

常见交付包括 MP4 视频、独立音频、SRT 字幕、FCPXML 和完整工程数据。具体选项取决于当前版本和导出入口。

## 透明背景怎么导出？

当前产品路径支持 ProRes 4444 MOV。透明 WebM 首版未开放；回退到 H.264 时不会保留透明通道。

## 卸载会删除工程吗？

不要依赖卸载程序保留或删除数据。卸载前应导出重要工程、复制源素材和成片，并记下本地媒体目录。

## 如何反馈 Bug？

使用本仓库 Issue 模板，提供版本、系统、复现步骤、预期与实际结果，以及脱敏截图或诊断包。安全漏洞按 [SECURITY.md](../SECURITY.md)私下报告。
